## ✨ About This Project

This is my personal portfolio — built from scratch to represent my work, skills, and development style. The goal was to create an experience that feels polished, modern, and intentional, without relying on any UI framework.

Every section — from the animated scroll reveals to the responsive layout — was hand-coded to reflect how I approach real-world projects: clean structure, attention to detail, and performance in mind.

---

## 🚀 Featured Projects

| Project | Description | Stack |
|---|---|---|
| **Budget Simulator** | Interactive tool that calculates project costs based on user specs | React, TypeScript, Tailwind |
| **Project Dashboard** | Analytics panel with metrics and performance indicators | Next.js, Chart.js, API |
| **Kanban Board** | Task management with drag & drop and real-time view | React, TypeScript, Tailwind |

---

## 🛠️ Tech Stack

```
HTML5 · CSS3 · JavaScript (ES6+)
```

**Highlights:**
- Vanilla JS `IntersectionObserver` for scroll-triggered animations
- CSS Grid & Flexbox for fully responsive layout
- No frameworks — just clean, semantic HTML and modular CSS
- Deployed on **Vercel** for blazing-fast delivery

## ⚙️ Running Locally

No build step required — just clone and open.

```bash
# Clone the repository
git clone https://github.com/YanPorfirio/NewPortfolio.git

# Navigate into the folder
cd NewPortfolio

# Open in your browser
open index.html
```

Or use the [Live Preview](https://new-portfolio-delta-silk.vercel.app) directly.
